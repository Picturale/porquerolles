# AGENTS.md

## Cursor Cloud specific instructions

### What this repo actually is (scope)
The active product is the **Porquerolles Portail**: a static [Astro](https://astro.build) site in `site/` fed by Python "connecteurs" in `conception/moteur/connecteurs/`. All active development happens here (see `PLAN-ATELIER.md`).

The root `src/`, `functions/`, `android/`, and `ios/` trees are an **abandoned Vision Picturale / Porquerolles Connect social app** (`PLAN-ATELIER.md` §1 marks them "Hors périmètre"). Do **not** set up or run them unless a task explicitly asks: they require Firebase owner credentials / emulators that are not provisioned here. The root `README.md` describes that old app and is outdated (e.g. it mentions port `5173` and a `core-app/` that no longer exists) — trust `PLAN-ATELIER.md` and `conception/` instead.

### Running the portal (active product)
- Dev server: `npm --prefix site run dev` — serves at `http://localhost:4321/porquerolles/`. Note the `/porquerolles/` base path (set in `site/astro.config.mjs`); the bare `/` and `/porquerolles` without trailing slash will 404, and internal links go through `site/src/lib/url.js`.
- Build: `npm --prefix site run build` → output in `site/dist/`. There is no separate lint/test for the site yet; the build is the correctness check. (The pytest/vitest CI described in `PLAN-ATELIER.md` Phase B does not exist yet.)

### The Python engine ("moteur")
- Only dependency is `pyyaml` (already available in the base image; no requirements file exists).
- Connectors hit the network:
  - `python3 conception/moteur/connecteurs/vent.py [--tolerant]` fetches Open-Meteo wind and writes `conception/donnees/etat-du-jour.json`.
  - `python3 conception/moteur/connecteurs/feu.py [--tolerant]` fetches the wildfire level and writes `conception/donnees/risque-incendie-du-jour.json`.
- `--tolerant` (used by `.github/workflows/refresh.yml`) means a network/source failure exits 0 and writes nothing, keeping the last committed JSON.
- The two `conception/donnees/*-du-jour.json` files are **derived data**, regenerated by the connectors / the hourly `refresh.yml` workflow. Don't hand-edit them, and don't include a local refresh of them in an unrelated code PR.

### Data flow (how a page gets live values)
Connector → `conception/donnees/*.json` → read by `site/src/lib/*.js` at Astro build/dev time → rendered into pages like `/porquerolles/aujourdhui/`. After running a connector, the dev server picks up the new JSON on reload.
